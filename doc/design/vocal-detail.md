# 虚拟歌手详情

网页路径为 `/vocals/:vocalId`，赤羽示例为 `/vocals/304`。只展示本地已配置的角色基本信息，不依赖后端；`/vocals` 仍保留为列表待开发入口。详情页选中「虚拟歌手」导航。

## 数据范围

资料来自 [vocal-frontend-info.json](../../frontend/src/constants/vocal/vocal-frontend-info.json)，按 `vocal_list.id` 查找，以 `group_id` 关联 `group_list`。使用既有的稳定前端编号，不按名字推断数据库中的关联，也不把编号当成 `processed_videos` 已支持的歌手 ID。

当前 `processed_videos` 的歌手字段尚为空且缺少规范 ID，无法据此查询歌曲关联。本页不新增 API，不调用视频、创作者或搜索接口，不展示歌曲列表、投稿数、播放量或空的统计卡片，也不把无法查询误写为「作品为零」。`official_producer_id: 0` 不作为有效官方账号使用。

展示姓名、所属企划 / 机构、性别、设定年龄、生日、身高和声源；形象设计、体重、星座、出身地区、代表物、使用许可、性格、外貌及特点按本地已配置内容显示。没有配置的可选信息不编造，年龄不推算出生年，生日只显示月日。初音未来的使用许可为「CC BY-NC 3.0 Unported」。其他已配置歌手也可通过自身 ID 查看资料。

五维介质和 Vsinger 为对应机构的展示名称，机构全名随左侧资料保留。官方、立绘来源和版权说明仅使用配置提供的 HTTP(S) 链接，入口叠放在立绘下缘，外链在新标签页打开；不从机构主页推断个人账号或素材许可。来源按钮按域名直接显示「立绘来源：Bilibili」「立绘来源：Booth」「立绘来源：VCPeida」「立绘来源：微博」「立绘来源：SONICWIRE」，对应 `bilibili.com`、`booth.pm`、`vcpedia.cn`、`weibo.com`、`sonicwire.com` 及其子域名；未知平台保留通用来源文案，不重复存储平台名称。

声源配置沿用 `official_persona.cv`：起礼为「悠茗月尘」，起复为「这是一根手指」。页面直接展示此字段，不推断或查询其他账号资料。

## 页面与配色

页面采用紧凑的角色海报式布局：标题和精简资料贴近透明立绘，立绘直接位于 Canvas 上，不包在卡片或图片底板中。资料使用无边框键值列表：每行标签按最长标签对齐，所有内容从同一条左边缘起排，标签用较小字号，内容用正文字号。性别、年龄及特点使用无边框 Tag，外链操作使用 Button。角色编号仅用于路由和内部关联，不显示编号文案或背景水印。

桌面端标题、资料在左，立绘在右，两列作为紧凑组合在画面中居中；图片在自身列内居中，列宽随立绘高度调整。窄屏上方放标题，下方让资料与立绘并排。收紧内外留白，立绘高度随视口调整，优先使当前基本信息在常规首屏内展示，不通过裁剪立绘或隐藏资料来限制滚动。官方及来源入口叠放在立绘下缘，不另占页脚。立绘完整展示，遵循系统减少动态效果设置。图片暂缺或加载失败时保留资料并显示立绘暂缺占位；未配置的 ID 与非法 ID 分别显示对应结果页，可进入赤羽示例。

赤羽的文字与标签强调色使用现有 `--highlight-red`，其他角色暂沿用 highlight 蓝色。控件颜色由 `theme.css` 的 `--vocal-*` 语义变量派生，并在当前角色容器与日夜主题下重新计算。标题字号使用 `--font-size-vocal-name`。

`support_color_list` 是角色资料：显示色号及 36px × 12px 的小矩形色块，不喧宾夺主。底纹使用 SVG pattern 填充斜线的几何四边形与圆形，不使用弥散渐变或光晕；第一、第二应援色分别用于两组斜线，只有一种颜色时复用该色，缺色时回退为既有 highlight。四边形斜线更细、更淡，圆形斜线更粗、更明显；透明度和线宽分别由 `--vocal-hatch-{square|circle}-opacity`、`--vocal-hatch-{square|circle}-width` 在 `theme.css` 集中控制，白天比夜间更粗、更不透明。

几何底纹位于整个角色区域的背景层，覆盖约屏幕三分之一的面积量级，可延伸至部分文字后方；不受立绘容器裁切，也不撑大页面布局。背景宽度受视口约束，不接收鼠标或键盘事件。叠在图形上的小字使用正文主题色保证可读性，按钮保留 Normal 的 Surface 背景；来源长标签在窄屏自然换行。

立绘在视口允许时最大高度为 760px，随图幅宽度与文字组成居中的整体；窄屏优先为立绘分配更多横向空间。官方及来源使用规范 Normal 按钮：36px 基准高度、14px 文字、无边框，普通 / 悬停 / 焦点均使用共享主题变量，不另设小字号或紧凑尺寸。

应援色仅接受有效的六位 HEX 数据，通过局部 CSS 变量用于色块和半透明几何底纹。这是角色资料展示的限定用途，不替换按钮、正文、标签、焦点等项目语义配色；其他规则继续遵循[视觉规范](visual-spec.md)。

## 图片与验证

配置中 `/public/vocals/chiyu.png` 规范化为 Vite 实际提供的 `/vocals/chiyu.png`；其他本地图片使用同样规则。仅使用仓库已有素材，不生成替代立绘。

前端测试覆盖编号解析、全部已配置图片的实际存在性、图片路径规范化、缺图、生日和外链校验。页面渲染检查覆盖赤羽、其他角色、缺图和未知编号；常规视觉验收由用户在 `/vocals/304` 手动完成。
