# 单视频播放过线与量级筛选

视频详情 `/videos/:aid` 在「数据趋势」之后增加「播放过线记录」卡片：列出该视频已收录的播放里程碑，并可按过线值的量级筛选。

## 数据来源

只读 `hantang_dynamic.video_collection_gate_crossings`，不根据 `video_daily` 反推、补造或回填过线记录。

- 每行是一次过线：`gate_value`（过线值）、`previous_view` / `current_view`（识别到过线前后的累计播放）、`crossed_at`（记录时间）。
- `(aid, gate_value)` 唯一，同一视频同一过线值最多一行。
- 采集侧按量级生成过线值：小于 1 万为 1000 的整数倍，1 万至 10 万为 1 万的整数倍，10 万及以上为 10 万的整数倍。页面如实展示库内记录，包括历史补录产生的其他整数倍值。

## API

`GET /videos/{aid}/gate-crossings`

- `aid` 规则与视频详情其他接口一致：不带前导零的正 64 位整数；非法返回 400。
- 成功返回 `result: { aid, rows }`；`rows` 按 `gate_value` 降序、同值按 `id` 降序排列。
- 每行 `{ gateValue, previousView, currentView, crossedAt }`。`previousView` / `currentView` 缺失时为 `null`，真实零保留；`crossedAt` 为 ISO 8601 时间字符串。
- 视频没有过线记录时返回 200 与空数组，不用 404 表达数据缺失；查询失败返回 500，不泄露 SQL 或内部异常。
- 不提供分页或服务端量级筛选，量级筛选在前端完成。单视频记录数受采集历史限制，当前库内最多 52 行，一次返回全部。

## 页面

- 卡片标题「播放过线记录」，位于「数据趋势」之后；沿用 `DsTable`、`DsPagination` 与项目主题变量，不硬编码颜色。
- 列：过线值（中性 `ds-chip`，右对齐）、上次播放、当前播放、增量、过线时间。增量为 `currentView - previousView`，任一端缺失时显示 `—`；时间使用 `RelativeTime`，悬停或键盘聚焦可查看绝对时间。
- 量级筛选使用 Ant Design `Select`，选项为全部 / 整千 / 整万 / 整十万 / 整百万 / 整千万 / 整亿，并显示该视频对应记录数；没有记录的档位禁用。各档范围：整千 1,000–9,999，整万 1 万–9.9 万，整十万 10 万–99.9 万，整百万 100 万–999.9 万，整千万 1,000 万–9,999 万，整亿 1 亿及以上。筛选只影响展示，不重新请求。
- 切换视频取消旧请求；加载、加载失败（可重试）与「该视频暂无过线记录」分别呈现。分页每页 10 条，筛选变化回到第一页。

## MOCK

MOCK 没有真实过线样本，`fetchVideoGateCrossings` 返回空数组，不生成演示过线值；卡片按无记录展示。
