# 视频标注复核

入口：管理配置 → 内容 → 视频标注复核（`/admin/content/video-review`），沿用管理入口开关。人工复核区用于核对、修改和另存现有1000条参考答案及同契约的Task输出；顶部执行卡片用于显式启动Qwen任务，两者均不写业务数据库。

页面顶部的「Qwen批量标记」为执行入口：点击「开始执行」后由既有Java任务分批标记1000条原始样本，网页每秒读取成功/失败数、活跃HTTP请求、API平均耗时、每分钟处理数、剩余数量、已用时间和预计完成时间。启动前可下拉选择1/4/8/16/32/64并发，默认8，运行中配置固定；每批仍为20条。仅点击才执行；可以下载成功结果及独立运行统计，人工参考答案不被覆盖。该本机执行入口与下面的人工复核工作区分开，密钥仅留在Java后端；运行方式见[任务说明](../../script/uniseek/README.md#网页执行)。

## 操作

- 首次打开自动载入用户确认复核完毕的`script/uniseek/reference_answers.reviewed-final.json`；浏览器已有草稿则优先恢复。点击「载入最终参考答案」可显式切换，未导出修改仍按现有方式提示。原始样本、参考初稿和第一次纠正版独立保留，均不被页面改写。
- 按标题/aid搜索，筛选含不确定结果或本机已调整的条目。默认每页50条，可选20/50/100/1000条。列表直接展示标题、是否歌曲、是否虚拟歌手、演唱语言和备注入口，不必逐条打开查看结果。
- 视频范围提供「全部视频」「虚拟歌手歌曲」「非虚拟歌手歌曲」三项，长选项使用无边框Select。「虚拟歌手歌曲」严格要求`is_song=是 && is_virtual_singer=是`；第二项是该谓词的逻辑非，因此非歌曲、非虚拟声源、混合及不确定等其余条目全部保留，两个范围不重叠且并集为全部视频。范围与其他筛选按AND叠加，切换后回第1页，修改标签后即时更新归属，导出不受筛选影响。
- 取消常驻左右分栏及复核页960px宽度限制，列表铺满可用区域；侧栏宽度在桌面按视口适当缩放。宽容器用DsTable，窄容器自动改为卡片，三个维度仍直接可见；只有点击「修正」才打开自适应宽度的Ant Design Drawer。
- 是否歌曲、是否目标虚拟歌手使用Ant Design单选按钮，完整保留是/否/不确定及歌声混合。演唱语言用可搜索多选，已有文件中的其他规范语种自动加入选项；界面语言切换不改变JSON中的汉语枚举值。
- 「无语言」与其他语种互斥，清空选择记为「未知语言」。保留已知语种与未知语言并存；不确定结果也可以人工确认。歌曲、声源与语言分别编辑，不做级联清空。
- 按用户的「未修改默认正确」口径，载入、恢复草稿和导入时批量采用现有判断，将已载入条目的`review.status`记为「已确认」。三维标签及原始备注均不因此改变，「不确定」不会变成「是」。无需逐条确认；导出一次即可获得全部采用后的结果，这一状态表示用户采用结果，不表示逐条打开核验过视频。
- 可疑项在抽屉里改标签或备注，改动即被采用并暂存，关闭即可回到列表。条目因修改不再符合筛选时，抽屉仍保留当前条目，防止输入中途切换。列表标记本机调整过的条目，计数和编号清单仅在浏览器工作区保存，不新增JSON契约字段；导入副本仍保留修正标签，工作区调整计数重新开始。

## 保存与文件契约

参考答案和Task使用[同一个v1契约](../../script/uniseek/analysis-result.schema.json)。前端复用契约枚举与字段定义，导入时校验完整结构、唯一且可安全表示的aid、条数、标签、语言和调用用量。拒绝不兼容文件而不丢弃未知字段或覆盖当前工作；支持部分/失败任务的已完成结果，不补造尚未处理的条目。文件大小上限20 MB，适合当前1000条复核，不作为20万条一次载入的编辑器。

页面只修改每条的`output`及`review`，原样保留`aid`、`input`、任务来源、条数、状态和批次用量。`status=completed`仍表示推理/初稿生成覆盖范围，不表示人工确认完成。

每次编辑开始异步IndexedDB事务保存当前工作区，后续事务按顺序执行；页面提示正在暂存、已暂存或失败。离开页面不取消已开始的写入；暂存未成功且有新修改时，关闭/刷新提示防止丢失。暂存只属于当前站点、浏览器和设备，不等于文件备份，也不跨标签页协同编辑。

「导出复核JSON」使用Blob下载新的`.reviewed-<UTC时间>.json`文件，不具备覆盖用户磁盘源文件的权限。切换文件前若有未导出修改，显示确认提醒；导出不受当前筛选/分页影响，始终包含已载入的全部条目。导入已导出文件可继续复核。人工复核区无后端写入、不读取密钥配置、不调用LLM；参考答案按需从单独资源载入，顶部Qwen执行区通过前述本机接口独立运行。
