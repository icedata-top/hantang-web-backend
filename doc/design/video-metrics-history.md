# 单视频历史数据与趋势

视频详情 `/videos/:aid` 在简介下方展示「数据趋势」卡片。默认累计值，可切换每日增量；七项指标与总览页顺序、highlight 配色一致。日期范围使用 Ant Design RangePicker，模式使用 Segmented。

## 累计快照 API

`GET /videos/{aid}/daily-metrics?startDate=2026-10-20&endDate=2026-10-22`

起止均为 **快照日期，包含边界**。响应沿用 `ResponseDTO`，`result` 包含：

- `aid`：查询的视频 ID。
- `startDate`、`endDate`：请求的快照起止日期，格式 `YYYY-MM-DD`。
- `rows`：按日期升序，每个自然日恰有一行。
- 每行的 `date` 是快照日期，`snapshotMissing` 明确表示该日期是否整日未收录。
- 每行 `indicators` 固定包含 `view`、`like`、`coin`、`favorite`、`share`、`reply`、`danmaku` 七个累计指标。缺失指标保留 JSON `null`，真实零保留 `0`。

仅查询 `hantang_dynamic.video_daily`，使用绑定参数按 aid 和日期范围筛选。不在后端计算 delta，不回退到其他日期，不插值，也不把 NULL 补成零。整日无记录时返回 `snapshotMissing: true`，且七项全部为 `null`；快照存在但部分字段为空时返回 `snapshotMissing: false`，保留各字段缺失状态。

`aid` 必须是不带前导零的正 64 位整数；日期必须为有效的四位年份日历日期（0001–9999 年），开始日期不晚于结束日期，单次最多 366 个快照日期。非法参数返回 HTTP / code 400。查询失败或同一 aid 同一天存在重复快照返回 500，不任意选取或聚合重复记录。范围内全部无记录仍返回 200 和完整的空缺日期行；该接口不根据日快照判定视频是否存在。

## 日期范围与一阶差分

UI 沿用总览页的业务日口径。选中开始日 S 至结束日 E（包含两端），需要 S 至 E+1 的凌晨累计快照，因此前端请求上述 API 时将 `endDate` 传为 E+1。

- 累计模式展示 S 至 E+1 的全部快照点，横坐标为实际快照日期。
- 增量模式展示 S 至 E，每天 D 的值为 `snapshot[D+1] - snapshot[D]`。横坐标为业务日 D。
- 只有同一指标在相邻两天都存在时才能作差；任一端缺失时，当天该指标增量为 `null`。不跨缺失日期相减，不把跨日差值当作某一天的增长。
- 单项缺失只影响该项；真实零和负增量原样保留。负增量可能来自源累计值的回退，不强制截断为零。

默认最近 7 天，结束日为昨天；提供最近 7 / 14 / 30 天快捷范围。日期下限为 2025-10-01，最多选 30 个业务日，与总览页共用同一组范围规则。日快照只标明观测日期，不代表已取得精确采集时分秒。

## 播放量摘要与缺失展示

区间播放增长为 `view[E+1] - view[S]`；日均为该增长除以所选业务日数 `E-S+1`，展示最多两位小数。

中间有缺口但两端播放量有效时，仍能准确计算端点之间的总增长，日均按全部所选天数计算，不能改用已知增量的和或有效天数作分母。页面同时说明中间的每日增量暂缺。起点或终点播放量缺失时，总增长与日均一起显示暂缺，不静默缩短区间，也不把首个可用点当作起点。

折线保留所有日期和 NULL，在缺失处断线；日期提示列出七项指标，缺失值写作「暂缺」。卡片显示未收录快照和部分指标缺失的日期数，可展开查看具体日期、指标以及增量模式下无法计算的业务日。全部缺失时明确显示暂无数据；请求失败单独提供重试，不与数据缺失混淆。

切换日期或视频会取消旧请求，旧数据不覆盖新范围。模式切换只在已有累计快照上计算，不重复请求。MOCK 没有真实日快照样本，返回与 API 一致的明确缺失日期，不生成演示计数。

## 验证

后端测试覆盖严格参数校验、绑定参数、缺日补行、单项缺失、真实零、JSON NULL 和重复快照；HTTP 测试区分 200 空缺、400 参数错误和 500 查询错误。前端测试覆盖相邻日差分、缺口两侧、端点缺失、中间缺口的总增长、零与负增量、单日范围、补录恢复、跨月跨年和图表 NULL / 提示内容。
